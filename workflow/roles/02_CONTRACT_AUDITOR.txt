MISSION

Read-only validation of runtime architecture, public API, manifest, reports, CLI behavior, stage execution, cleanup, and persistence. Do not judge visual fidelity.

2. Inventory reusable field, table, cell, rendering, fitting, label, report, CLI, and validation infrastructure.
3. Confirm these public functions can be preserved:
   get_canonical_schema, get_generator_manifest, get_available_fields,
   assess_compatibility, propose_missing_values, resolve_record,
   validate_record, render_document, validate_output_contract,
   generate_edge_cases, self_test, audit_generator.
4. Record exact public signatures and defaults.
5. Confirm output_pdf defaults to false.
6. Identify only genuine runtime defects that justify edits outside the edit zone.
7. Confirm the source scan remains a render_document input.
8. Search statically for OCR, PDF text extraction, hidden-layer access, and artificial degradation paths.

10. Produce a preflight risk list and reusable-runtime map.
11. Treat target-specific edit-zone placeholders, an empty template catalog, and a
    document-family mismatch as expected adaptation work, not preflight failures.

    Generator Engineer and must include complete issue records and exact evidence.

2. Verify every public function and CLI command.
3. Run self_test and confirm it covers all required static checks.
4. Confirm canonical input, local input, and external key mappings.
5. Confirm incomplete records, optional omissions, synthesis, derivation, aliases, and list strategies.
6. Confirm assess_compatibility returns exactly the required keys.
7. Confirm proposals are deterministic and explicitly distinguish synthesized from derived.
8. Confirm manifest.json is deterministic serialization of get_generator_manifest().

10. Verify production sample directories contain only the exact permitted files.
11. Verify validate_output_contract independently checks files and labels and does not trust hidden metadata or report claims.

13. Run one PNG/PDF equivalence smoke test.
14. Verify sample and generator report envelopes, required checks, required metrics, error schema, and CLI exit-code equality.
15. Verify audit stages are isolated and resumable rather than one unbounded image-heavy operation.
16. Verify the visual-review envelope is current, hash-bound, reviewer/writer identities differ, all required checks are explicit, and all 17 edge cases are individually approved.
17. Verify successful cleanup leaves only generator.py, manifest.json, and generator_report.json.
18. On failure, verify retained diagnostics are explicitly indexed by an error artifact.
