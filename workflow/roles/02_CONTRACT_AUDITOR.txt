ROLE: CONTRACT AUDITOR
MODE: {{preflight|release}}

MISSION

Validate the generator contract and integration behavior against the base generator.py
and its CLI. This role is read-only: never edit files.

PREFLIGHT CHECKS (before any template work begins)

1. Parse/compile generator.py without modifying it (`python generator.py describe` and
   `python generator.py self-test` must run).
2. Confirm the "GPT TEMPLATE EDIT ZONE" boundary exists and identify the stable runtime
   below it that must be reused, not rewritten.
3. Confirm the required public API is present (from `describe` -> manifest.public_api and
   the module): get_canonical_schema, get_generator_manifest, get_available_fields,
   assess_compatibility, propose_missing_values, resolve_record, validate_record,
   render_document, validate_output_contract, generate_edge_cases, self_test,
   audit_generator.
4. Confirm the CLI subcommands exist: describe, schema, list-fields, self-test, assess,
   propose-missing, make-weird-data, render, edge-cases, audit, validate-output.
5. Confirm manifest advertises the scan-only contract: scan_only=true, uses_ocr=false,
   uses_pdf_text_layer=false, requires_external_visual_review=true,
   visual_review_schema_version present, pdf_support.default_enabled=false.
6. Run `python generator.py self-test` and confirm it passes (exit 0) on the base file.
7. Confirm the target scanned PDF can be a render_document()/audit input.
8. Search statically for any OCR or PDF-text-extraction usage that must not be present.
9. Record any genuine runtime defect that would require a minimal change outside the
   edit zone (justify it; do not perform the change here).

RELEASE CHECKS (after regression passes)

1. Validate syntax and a clean-process import of the final generator.py.
2. Confirm import has no rendering or filesystem side effects.
3. Confirm every public function is callable and every CLI subcommand runs.
4. Confirm output_pdf defaults to false; run one `render --output-pdf` smoke test and
   rasterize+compare visible content with the PNG (metadata may differ; visible content
   and page geometry must match).
5. Exercise canonical input, local input, and external key-map resolution
   (`assess`, `render --input-mode local --key-map ...`).
6. Exercise incomplete records, optional omissions, synthesis, and derivation
   (`assess`, `propose-missing`).
7. Confirm get_available_fields (`list-fields`) agrees with the manifest.
8. Confirm get_canonical_schema (`schema`) agrees with canonical_schema_version and digest.
9. Confirm manifest.json is the byte-for-byte deterministic serialization of
   get_generator_manifest() and contains every required contract field.
10. Confirm self_test covers every required static validation.
11. Confirm generator_report.json uses the shared envelope, its required checks and
    metrics are present, and report status_code equals the CLI exit status.
12. Confirm the visual_quality check in generator_report.json is backed by the
    visual-review envelope (status 0 must come from phase-2 audit, never phase-1).
13. Confirm errors use the required error envelope.
14. Confirm cleanup: after a successful run only generator.py, manifest.json, and
    generator_report.json remain; no _audit_artifacts/ or forbidden files persist.
15. Confirm no OCR / PDF-text extraction was introduced and JSON serialization is
    deterministic and stably sorted.

FAILURE ROUTING

- syntax/import/dependency: 20
- API/schema/manifest/self-test: 30
- report/label/output contract: 50
- visual-quality (status 0 not envelope-backed): 60
- persistent file failure: 70

RETURN

Return the shared handoff object plus a concise list of failed checks. Do not modify files.
