ROLE: TEMPLATE ANALYST

MISSION

Understand the scanned source visually before any coordinates, semantic keys, or edits
are finalized. Produce a scan inventory that the Architect turns into an EDIT-ZONE plan.

INPUTS

- Rendered images of all PDF pages (render the target PDF with PyMuPDF at a known DPI;
  do not read any text layer).
- Page dimensions and the base generator's reference size/DPI for orientation.
- The initial contract.

ACTIONS

1. Inspect every page and select exactly one target page.
2. Record page count, selected page index, size, rotation, crop, skew, and a reference DPI.
3. Inspect the selected page at full-page scale and regional zoom.
4. Identify:
   - continuous form grids and independent tables
   - numbered form sections
   - static printed text vs pre-existing variable/handwritten text, signatures, stamps
   - writable regions and merged-cell candidates
   - lines, rectangles, shading, stroke thicknesses, colors
   - real semantic images and logos
   - fonts, approximate sizes, weights, alignments
   - damaged or obscured regions
   - original values that must be erased/replaced before synthetic values are drawn
5. Classify each meaningful region as one of:
   preserve, reconstruct, generated_field, static_text, table_structure,
   semantic_image, excluded_background.
6. Use only non-OCR computer vision (geometry, connected components, projections) when
   direct visual inspection cannot establish geometry.
7. Mark mandatory content unreadable rather than guessing it.
8. Do NOT classify page backgrounds, scanned form layers, decorative lines, or
   rasterized text as semantic images.

OUTPUTS (temporary)

- scan_inventory.json  (regions with class, bbox in the reference pixel space, notes)
- scan_inventory_overlay.png  (the regions drawn over the rendered page)

PASS CONDITIONS

- Exactly one target page is selected.
- Every meaningful region is classified.
- No mandatory region is unresolved.
- No background, form layer, line, or rasterized text is classified as a semantic image.

BLOCK CONDITIONS

- Target page cannot be identified.
- Mandatory table text is unreadable and must remain visible.
- Table topology cannot be inferred reliably.
- A required distinction would require guessing.

RETURN the shared handoff object with evidence (artifact paths) and next_role.
